# project-foundation

Codex skill for setting up a lightweight collaboration environment for new or explicitly reorganized projects.

## Install

Copy this folder into a skill directory Codex loads, for example:

```sh
mkdir -p ~/.agents/skills
cp -R project-foundation ~/.agents/skills/project-foundation
```

Start a new Codex session and check that `project-foundation` appears in the available skills. Some Codex environments use a different skill location; follow that environment's documentation.

The skill relies on the Markdown files under `references/`; keep them beside `SKILL.md`.
